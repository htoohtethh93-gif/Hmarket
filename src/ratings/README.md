# H MARKET — Ratings / Reviews Module V1

Unified feedback foundation for:
- Shops
- Products
- Riders
- Transport services
- Accommodation

Includes:
- Rating dashboard
- Shop reviews
- Product reviews
- Rider ratings
- Transport ratings
- Accommodation reviews
- Moderation
- Reported reviews
- Review settings

Important:
- V1 is UI/scaffold only.
- Reuse existing `shop_ratings` and `rider_ratings` tables.
- Do not create duplicate rating tables during the foundation stage.
- Product, transport and accommodation review storage should be added
  only after the final database audit confirms what is actually needed.
- Reviews should normally be eligible after a completed order/delivery/booking.
- Partner replies and moderation should use status/visibility controls.
